# Balé Popular do Recife — Site Oficial

Base do novo site institucional do Balé Popular do Recife.

## Direção
- Visual editorial e internacional
- Responsivo para desktop, tablet e celular
- Estrutura preparada para português e inglês
- Foco especial nos 50 anos (1977–2027)
- Fotografias reais do acervo serão inseridas na etapa de curadoria

## Estrutura inicial
Home, O Balé, Método Brasílica, Espetáculos, Acervo, Agenda, 50 Anos, Imprensa e Contato/Contratação.

## Desenvolvimento
A primeira versão usa HTML, CSS e JavaScript sem dependências de build para permitir publicação gratuita e simples. A arquitetura pode evoluir posteriormente sem perder o conteúdo ou a identidade definida.
